# P7.3 — Mobile Bugs

These bugs were found during real-device testing.

They were reproduced on:

* iPhone 17 Pro Max / iOS 26.5.2 / Safari
* Android / Chrome
* Old/cheap Android / Chrome

**Important:** Do not modify ClickUp. These bugs are tracked only in this file.

---

## BUG-D-001 — Hamburger menu has white background and low text visibility

**URL:**
https://dumnica.vercel.app/en

**Severity:** Medium

### Problem

When the hamburger menu is opened on mobile, the menu has a white background while the navigation text is white.

The text is difficult to read.

### Expected

The mobile menu should use the intended dark background with clearly visible navigation text.

### Reproduce

1. Open the website on mobile.
2. Tap the hamburger menu.
3. Check the menu background and text contrast.

## BUG-D-005 — Lead form submission fails on deployed website

**URL:**
https://dumnica.vercel.app/en/afarizmi/dumnica-residence?njesia=A-3-12

**Severity:** High

### Problem

Submitting the "Interesohem" form on the deployed Vercel website fails with:

> "Shërbimi i emailit nuk është konfiguruar ende."

The inquiry is not sent.

### Expected

The form should successfully submit and send the inquiry to the configured sales/team email.

### Reproduce

1. Open unit A-3-12.
2. Open "Interesohem".
3. Enter valid information.
4. Submit the form.
5. Observe the error.

### Investigation

First check whether the problem is caused by missing/incorrect deployment configuration such as `RESEND_API_KEY`.

Do not expose or commit any API keys.

# Fix Requirements

Before changing code:

1. Investigate all 8 bugs.
2. Identify shared root causes where possible.
3. Check the existing components and styles before creating new code.
4. Do not make unrelated changes.
5. Do not modify ClickUp.
6. Do not invent requirements.

After fixes:

1. Verify all 8 bugs.
2. Test on mobile responsive sizes.
3. Verify iPhone Safari behavior.
4. Verify Android Chrome behavior.
5. Run the project's normal checks.
6. Confirm that fixing one bug did not break another.
